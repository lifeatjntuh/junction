# Junction

Junction is the brand design guidelines for LifeatJNTUH — the student
platform for JNTUH life. It says what LifeatJNTUH looks like, sounds
like, and feels like. The design system is a part of it, not the whole
of it.

## What lives inside Junction

- **Brand** — colours, typography, logo, shapes, photography and the
  rules. Start here.
- **Design System** — the components and primitives as an npm package
  (`@lifeatjntuh/junction`), every one with a live demo.
- **Social Media Kit** — the templates from social-studio for posts,
  carousels and stories.
- **App Design Kit** — AppShell, EventCard, ProfileCard, ScheduleGrid
  and the app states, for the Event Tracker and Buddy apps.
