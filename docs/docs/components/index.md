# Components

Every UI component in the package, each with a live rendered demo of
the actual element, its props and its usage code. The demos on these
pages render the real components from `@lifeatjntuh/junction`, with the
Junction theme applied — not screenshots.

## Website parts

| Component | What it is |
| --- | --- |
| [Button](./button.md) | Pill button — primary, secondary, dark, ghost, link, soft, google, danger |
| [Panel](./panel.md) | Big soft rounded block in pastel or solid colours |
| [Tag](./tag.md) | Rounded pill chip for labels, roles and categories |
| [Heading](./heading.md) | Fredoka or Bricolage Grotesque headings |
| [Text](./text.md) | Body text in Plus Jakarta Sans |
| [Field](./field.md) | Label, helper and error wrapper for a control |
| [Input and Textarea](./input.md) | Pill input and multi-line text box |
| [Tabs](./tabs.md) | Radix tabs — pill and underline, with TabsList, TabsTrigger, TabsContent |
| [Sheet](./sheet.md) | Vaul bottom sheet — SheetTrigger, SheetContent, SheetClose |
| [Toast](./toast.md) | Context toasts — ToastProvider and useToast |
| [ThemeToggle](./theme-toggle.md) | Light / Dark / System switcher, plus useTheme |
| [Logo](./logo.md) | The @lifeatjntuh wordmark |
| [Container](./container.md) | Page-width wrapper (max 1320px) |
| [ChipGroup](./chip-group.md) | Single-select filter chips |
| [Reveal](./reveal.md) | Scroll fade-and-rise wrapper |
