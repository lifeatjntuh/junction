# Design System

The design system is **one part** of [Junction](../brand/index.md) —
the components, primitives, tokens and theme that the brand guidelines
describe, shipped as the `@lifeatjntuh/junction` npm package (0.1.0,
not published yet).

## What is in it

| Page | What it is |
| --- | --- |
| [Installation](../installation.md) | Install and set up the package |
| [Components](../components/index.md) | Every UI component, each with a live demo |
| [Tokens](../tokens.md) | Colours, pastels, fonts, radii, shadows — live swatches |
| [Theme](../tokens.md) | How the theme works, dark mode, customising |
| [Icons](../icons.md) | Solar, linear — the only icon set |
| [API](../api.md) | Full export list |

## The parts

- **Website parts** — Button, Panel, Tag, Heading, Text, Field,
  Input, Textarea, Tabs, Sheet, Toast, ThemeToggle, Logo, Container,
  ChipGroup, Reveal. See [Components](../components/index.md).
- **App parts** — AppShell, AppState, EventCard, ProfileCard,
  ScheduleGrid and friends. See the
  [App Design Kit](../app-design-kit/index.md).
- **Primitives and utilities** — the building blocks the components
  are made of: TabsList / TabsTrigger / TabsContent, SheetTrigger /
  SheetContent / SheetClose, `cn`, `layoutScheduleEvents`,
  `BlobmateAvatar`, `EventQuickCard`. See the component pages and
  [API](../api.md).

Every component page shows the live rendered UI first, then its props
and usage code — not code instead of the UI.
