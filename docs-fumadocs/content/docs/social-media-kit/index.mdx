The Social Media Kit is the **Content Creation Studio** for
@lifeatjntuh — built by [@muddassirhq](https://github.com/muddassirhq)
as the `lifeatjntuh/social-studio` repo
([github.com/lifeatjntuh/social-studio](https://github.com/lifeatjntuh/social-studio)).
It is a single self-contained `index.html` — open it in a browser or
host it anywhere, no build step.

It is **not** the website design-system social templates: the studio
is the kit to use for making stories and posts (see the
[brand rules](/docs/brand/rules) for what every post must follow).

## How it works

1. **Template picker**, grouped by Post / Carousel / Story, with live
   previews at true export size.
2. **Canvas editor:** edit headline, body, date/time/venue, club/person,
   credit, colours and photo. Post size picker where it makes sense:
   Square 1080×1080, Portrait 1080×1350, Story 1080×1920.
3. **Image controls** (behind a collapsible panel): upload your own
   images, plus the brand's built-in photos/objects. Drag to pan, scroll
   to zoom, zoom/crop, Cover/Contain/Fill, frame presets, flip and align.
   Uploads are stored in localStorage in that browser only — they do not
   travel inside the exported file.
4. **Carousel builder:** thumbnail filmstrip, prev/next arrows and dots,
   add / duplicate / delete / reorder / retype slides, and mix different
   slide types in one carousel. Download the current slide or all slides
   in order.
5. **Caption + hashtag sets** per template, with a Copy button.
6. **Draft library:** save, duplicate, delete, search/filter, platform,
   status and scheduled date/time. At least 6 ready quick-start presets.
7. **Brand Kit page:** copyable colours, fonts and their roles, and the
   design system's Do / Don't rules.
8. **Download PNG** at the template's true export size — the download
   must match the preview exactly, including fonts, framing and colours.

## The templates

| Section | What is in it |
| --- | --- |
| [Posts](/docs/social-media-kit/posts) | Club event, creator shoutout, campus memory, announcement, WhatsApp Channel digest — 1080×1350. Full-bleed Photo of the Day (`photo-day`). |
| [Carousel](/docs/social-media-kit/carousel) | Cover, feature, steps and end slides — 1080×1350. Full-bleed photo slides (`carousel-photo`). |
| [Stories](/docs/social-media-kit/stories) | Event, photo of the day, question, LifeOps role call — 1080×1920 (`story-photo`). |

Every template uses real, business-specific example copy — not lorem
ipsum — and short headlines in the brand's headline style (Bricolage
Grotesque, all caps, under six words for social headlines).

## Sizes

| Format | Size | Use |
| --- | --- | --- |
| Portrait post | 1080×1350 | Instagram posts, WhatsApp Channel |
| Portrait / carousel | 1080×1350 | Carousel slides |
| Story | 1080×1920 | Instagram stories, WhatsApp status — keep the top 250px and bottom 300px clear for app controls |
