Every UI component in the package, each with a live rendered demo of
the actual element, its props and its usage code. The demos on these
pages render the real components from `@lifeatjntuh/junction`, with the
Junction theme applied — not screenshots.

## Website parts

| Component | What it is |
| --- | --- |
| [Button](/docs/components/button) | Pill button — primary, secondary, dark, ghost, link, soft, google, danger |
| [Panel](/docs/components/panel) | Big soft rounded block in pastel or solid colours |
| [Tag](/docs/components/tag) | Rounded pill chip for labels, roles and categories |
| [Heading](/docs/components/heading) | Fredoka or Bricolage Grotesque headings |
| [Text](/docs/components/text) | Body text in Plus Jakarta Sans |
| [Field](/docs/components/field) | Label, helper and error wrapper for a control |
| [Input and Textarea](/docs/components/input) | Pill input and multi-line text box |
| [Tabs](/docs/components/tabs) | Radix tabs — pill and underline, with TabsList, TabsTrigger, TabsContent |
| [Sheet](/docs/components/sheet) | Vaul bottom sheet — SheetTrigger, SheetContent, SheetClose |
| [Toast](/docs/components/toast) | Context toasts — ToastProvider and useToast |
| [ThemeToggle](/docs/components/theme-toggle) | Light / Dark / System switcher, plus useTheme |
| [Logo](/docs/components/logo) | The @lifeatjntuh wordmark |
| [Container](/docs/components/container) | Page-width wrapper (max 1320px) |
| [ChipGroup](/docs/components/chip-group) | Single-select filter chips |
| [Reveal](/docs/components/reveal) | Scroll fade-and-rise wrapper |
