# Logo

<LogoDemo />

The @lifeatjntuh logo: the pink `@` ring mark plus the "lifeatjntuh"
wordmark in Fredoka with a pink `@`. Light tone (plum text) for
cream/pastel backgrounds; dark tone (white text) for plum surfaces and
photos.

## The @lifeatjntuh pill

Sign every post with the **@lifeatjntuh pill** — a fully round pill
with the handle in it. It is the signature on every post, carousel end
slide and story.

## Rules

- Don't stretch or squash the logo or photos.
- Don't recolour the `@` — it stays hot pink.
- The website keeps its mark as a local media asset, so the package
  does not bundle one — pass it as `markSrc` to the
  [Logo component](../components/logo.md) when you have
  it; without it, only the wordmark renders.
