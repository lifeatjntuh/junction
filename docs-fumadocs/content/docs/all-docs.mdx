## Brand

- [Junction](/docs) — the brand design guidelines for LifeatJNTUH, with the design system, the Social Media Kit and the App Design Kit as parts of it.
- [Brand](/docs/brand) — what Junction is: one look for the site, socials and apps.
- [Colours](/docs/brand/colours) — Plum, Cream, Hot pink, Orange, Violet, and six pastels.
- [Typography](/docs/brand/typography) — Fredoka website headlines, Bricolage Grotesque social headlines, Plus Jakarta Sans body, Lexend app screens.
- [Logo](/docs/brand/logo) — the pink @ ring mark, the Fredoka wordmark, and the @lifeatjntuh pill that signs every post.
- [Shapes](/docs/brand/shapes) — 32px panel corners, fully round buttons and chips, soft plum-tinted shadows.
- [Photography](/docs/brand/photography) — real campus photos, always credited; no stock photos of other campuses.
- [Rules](/docs/brand/rules) — the do's and don'ts every post, story and screen must follow.

## Design System

- [Design System](/docs/design-system) — the @lifeatjntuh/junction npm package: components, primitives, tokens and theme.
- [Installation](/docs/installation) — install with pnpm, import the theme, render your first components.
- [Tokens](/docs/tokens) — core colours, pastels, fonts, radii and shadows, as CSS variables and typed TypeScript constants.
- [Icons](/docs/icons) — Solar icons (linear) everywhere, via @solar-icons/react and @iconify/react.

### Components A–M

- [Components](/docs/components) — every UI component, each with a live demo, props and usage code.
- [Button](/docs/components/button) — pill-shaped button: primary, secondary, dark, ghost, link, soft, google and danger variants.
- [ChipGroup](/docs/components/chip-group) — controlled single-select chip group for filters.
- [Container](/docs/components/container) — centred page-width wrapper (max 1320px).
- [Field](/docs/components/field) — form field wrapper wiring label, helper text and errors to its control.
- [Heading](/docs/components/heading) — brand headings in Fredoka or Bricolage Grotesque.
- [Input and Textarea](/docs/components/input) — pill text input and multi-line text box.
- [Logo](/docs/components/logo) — the @lifeatjntuh wordmark in Fredoka with a pink @.

### Components N–Z

- [Panel](/docs/components/panel) — big soft rounded block in the pastel palette or a solid colour.
- [Reveal](/docs/components/reveal) — scroll fade-and-rise animation wrapper.
- [Sheet](/docs/components/sheet) — bottom sheet for filters, details and actions on small screens.
- [Tabs](/docs/components/tabs) — tabs with pill and underline variants.
- [Tag](/docs/components/tag) — rounded pill chip for activities, roles and small labels.
- [Text](/docs/components/text) — body text in Plus Jakarta Sans.
- [ThemeToggle](/docs/components/theme-toggle) — Light / Dark / System theme switcher.
- [Toast](/docs/components/toast) — context toasts with success, error and info tones.

### Primitives

- [cn](/docs/components/primitives/cn) — class-name merging helper (clsx + tailwind-merge).
- [layoutScheduleEvents](/docs/components/primitives/layout-schedule-events) — places events on a vertical day timeline, sharing width for overlaps.
