# Stories

Stories for Instagram and WhatsApp status — **1080×1920**. The
previews below are small-scale mock-ups; make the real story in the
studio ([Social Media Kit](./index.md)) and download the PNG at
1080×1920.

<SocialStoryDemo />

## The story templates

| Template | What it is for |
| --- | --- |
| **Event** (`StoryEvent`) | One event — title, club, date, venue |
| **Photo of the day** (`StoryPhoto` / `story-photo`) | Full-bleed campus photo, caption, photo credit |
| **Question** (`StoryQuestion`) | A question for followers — title, body, sticker slot |
| **LifeOps role call** (`StoryRecruit`) | One open role — role name, pillar |

## Safe areas

Stories keep the **top 250px and bottom 300px clear** for app
controls. Dashed boxes in the studio show where to drop the real
sticker. Never put text in those zones.

## Rules

- Grotesk for the big headline, round font for captions.
- Real campus photos, always with the photographer's credit.
- One 3D object per story at most, placed away from the text.
- Don't name admins — LifeOps credit goes to codenames.
